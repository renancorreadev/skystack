🚗 VFinance API — Rotas & Exemplos

Base URL: http://10.0.0.147 Direto na API: http://10.0.0.147:3000 Contrato: 0x3e299c…3305 Chain: Besu 1337
Autenticação: rotas marcadas com AUTH exigem um JWT. Gere em POST /api/auth/token e envie no header Authorization: Bearer <token>.
CORS: liberado para qualquer origem (Access-Control-Allow-Origin: *), aplicado pela API . Preflight OPTIONS responde 204.
Escritas on-chain (registro, marca/modelo, status, hash, server-config) levam ~5–10s (mineração no Besu) e são assinadas pela chave do servidor (= apiServerAddress).

🔄 Fluxo E2E (ordem recomendada)

  1. Gera token — POST /api/auth/token → guarda o JWT.
  2. Registra contrato — POST /api/contracts/ → retorna regConId, metadataHash, txHash.
  3. Consulta — GET /api/contracts/:regConId → pega o tokenId e dados on/off-chain.
  4. Leituras on-chain — por registry / chassi / hash / token, exists, brand/model, stats, total.
  5. Metadata off-chain — store / get / update / delete.
  6. Escritas/admin — registrar marca/modelo, atualizar status/hash, server-config, sync.

POST /api/contracts/ AUTH

Registra um contrato de financiamento (híbrido): grava dados primários on-chain (Besu) + metadados completos off-chain, ancorados por hash. Obrigatórios: regConId, numeroContrato, dataContrato e, dentro de vehicleData: chassiVeiculo, placaVeiculo, marcaVeiculo, modeloVeiculo, valorTotalContrato (> 0). Os demais campos vão para o metadata off-chain.

Request body
{
  "regConId": "DOC-1782406308",
  "numeroContrato": "87686",
  "dataContrato": "2025-09-11",
  "vehicleData": {
    "regConId": "DOC-1782406308",
    "numeroContrato": "87686",
    "dataContrato": "2025-09-11",
    "nomeAgenteFinanceiro": "CREDORA INTERNA",
    "cnpjAgenteFinanceiro": "11204397000150",
    "cpfCnpjProprietario": "64687376487",
    "nomeProprietario": "ANDRE SANTOS",
    "chassiVeiculo": "983279794327897",
    "placaVeiculo": "PL87686",
    "marcaVeiculo": "FIAT",
    "modeloVeiculo": "ARGO",
    "modelName": "ARGO",
    "tipoRestricacaoContrato": "ALIENACAO FIDUCIARIA",
    "valorTotalContrato": "30000.00",
    "quantidadeParcelasContrato": "36",
    "taxaJurosMesContrato": "1.00",
    "veiculoZeroKm": true,
    "anoFabricacaoVeiculo": "2025",
    "anoModeloVeiculo": "2025"
  }
}
cURL
curl -X POST http://10.0.0.147/api/contracts/ \
  -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d @contrato.json
201 Created
{
  "success": true,
  "message": "Contrato registrado com sucesso",
  "regConId": "DOC-1782406308",

PUT /api/blockchain/admin/server-config AUTH

Atualiza a base URL de metadados e o endereço do servidor (apiServer) on-chain. Campos: serverAddress, metadataBaseUrl.

⚠️ Trocar serverAddress para um endereço cuja chave a API não controla bloqueia futuras escritas. Mantenha 0xF08A60a634cbD8922B6e9c7aCFa391b402b80600 (chave atual do servidor).
Request body & cURL
curl -X PUT http://10.0.0.147/api/blockchain/admin/server-config \
  -H "Authorization: Bearer $TOKEN" -H "Content-Type: application/json" \
  -d '{"serverAddress":"0xF08A60a634cbD8922B6e9c7aCFa391b402b80600","metadataBaseUrl":"http://localhost:8080"}'
200 OK
{ "success": true, "message": "Server config updated successfully", "txHash": "0x6e7c3a01…b8a1ea" }
